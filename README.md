# Enterprise Job & Recruitment Management API

Enterprise-level Job & Recruitment Management System built with Python, FastAPI, PostgreSQL and Microservices Architecture.

## Architecture

- API Gateway
- Auth Service
- Job Service
- Application Service
- Notification Service

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT
- Redis
- Docker
- Pytest
- GitHub Actions
